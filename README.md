# MINKOWSKI Programming Language

## Overview

MINKOWSKI is a cutting-edge programming language designed for simplicity and efficiency. It features strong typing, easy-to-understand syntax, and rich library support.

## Features
- **Strong Typing**: MINKOWSKI enforces type safety, reducing runtime errors.
- **Flexibility**: Supports multiple programming paradigms including procedural and object-oriented programming.
- **Rich Standard Library**: Comes with a vast set of built-in functions and libraries to ease development.

## Comparison Operators
- `==`: Checks if two values are equal.
- `!=`: Checks if two values are not equal.
- `<`: Checks if the left value is less than the right value.
- `>`: Checks if the left value is greater than the right value.
- `<=`: Checks if the left value is less than or equal to the right value.
- `>=`: Checks if the left value is greater than or equal to the right value.

## Usage Examples
```minkowski
// Example of variable declaration and comparison
let a = 10;
let b = 20;

if (a < b) {
    print("a is less than b");
} else {
    print("a is not less than b");
}
```
